Nothing to do with the IDE. `ChatClient` is a **Spring AI library class** — `org.springframework.ai.chat.client.ChatClient`.

It's the object your Java services use to call an external AI API (Groq, Gemini, etc.). Think of it like `RestTemplate` or `WebClient`, but specifically for sending prompts to an AI and getting text back.

Your services that use it:
- [WordInsightService.java](interlinear-bible-api/src/main/java/com/interlinear/bible/service/WordInsightService.java) — generates word insights
- [AiTranslationService.java](interlinear-bible-api/src/main/java/com/interlinear/bible/service/AiTranslationService.java) — AI translation
- [ContextualGlossService.java](interlinear-bible-api/src/main/java/com/interlinear/bible/service/ContextualGlossService.java) — contextual glosses
- [WordBreakdownService.java](interlinear-bible-api/src/main/java/com/interlinear/bible/service/WordBreakdownService.java), etc.

The flow is:
```
Your Java service
  → calls ChatClient.prompt("...").call().content()
    → Spring AI sends HTTP request to Groq/Gemini/etc.
      → gets back the AI's text response
```

The `application.yml` config (`spring.ai.openai`) just tells Spring AI *which* API URL and key to use when it builds that `ChatClient` object at startup.

So when you want to add OpenRouter — you're just pointing `ChatClient` at a different URL with a different API key.
