```java
public String wordChat(Lexeme lexeme, String question) {
    StringBuilder sb = new StringBuilder();
    sb.append("Word: ").append(lexeme.getLemma());
    if (lexeme.getTransliteration() != null)
        sb.append(" (").append(lexeme.getTransliteration()).append(")");
    sb.append(" [").append(lexeme.getStrongsId()).append("]\n");
    if (lexeme.getPartOfSpeech() != null)
        sb.append("Part of speech: ").append(lexeme.getPartOfSpeech()).append("\n");
    if (lexeme.getEtymology() != null && !lexeme.getEtymology().isBlank())
        sb.append("Etymology: ").append(lexeme.getEtymology()).append("\n");

    if (lexeme.getMeanings() != null && !lexeme.getMeanings().isEmpty()) {
        sb.append("\nLexicon definitions:\n");
        List<LexemeMeaning> sorted = lexeme.getMeanings().stream()
            .sorted(Comparator.comparingInt(m -> sourceOrder(m.getSource())))
            .collect(Collectors.toList());
        int included = 0;
        for (LexemeMeaning m : sorted) {
            if (included >= 4) break;
            String text = m.getFullDefinition() != null ? m.getFullDefinition()
                        : m.getShortGloss() != null ? m.getShortGloss() : null;
            if (text == null || text.isBlank()) continue;
            if (text.length() > 400) text = text.substring(0, 400) + "…";
            sb.append("• [").append(m.getSource()).append("] ").append(text).append("\n");
            included++;
        }
    }
    sb.append("\nStudent's question: ").append(question.strip());
    return sb.toString();
}
```

**`src/main/java/com/interlinear/bible/service/WordChatService.java`** (NEW FILE):
```java
package com.interlinear.bible.service;

import com.interlinear.bible.config.ResilientAiRouter;
import com.interlinear.bible.entity.Lexeme;
import com.interlinear.bible.repository.LexemeRepository;
import com.interlinear.bible.util.PromptFactory;
import org.slf4j.Logger;
import org.slf4j.LoggerFactory;
import org.springframework.beans.factory.annotation.Qualifier;
import org.springframework.stereotype.Service;

import java.util.Comparator;
import java.util.List;
import java.util.Optional;

@Service
public class WordChatService {

    private static final Logger log = LoggerFactory.getLogger(WordChatService.class);

    private final LexemeRepository  lexemeRepo;
    private final ResilientAiRouter router;
    private final PromptFactory     promptFactory;

    public WordChatService(LexemeRepository lexemeRepo,
                           @Qualifier("mediumTierRouter") ResilientAiRouter router,
                           PromptFactory promptFactory) {
        this.lexemeRepo    = lexemeRepo;
        this.router        = router;
        this.promptFactory = promptFactory;
    }

    public Optional<String> ask(String strongsId, String question) {
        if (question == null || question.isBlank()) {
            throw new IllegalArgumentException("question must not be blank");
        }
        List<Lexeme> candidates = lexemeRepo.findByStrongsIdWithMeanings(strongsId, true);
        if (candidates.isEmpty()) {
            return Optional.empty();
        }
        Lexeme lexeme = candidates.stream()
            .max(Comparator.comparingInt(l -> l.getMeanings() != null ? l.getMeanings().size() : 0))
            .orElse(candidates.get(0));

        String systemPrompt = promptFactory.get("word-chat-system");
        String userPrompt   = promptFactory.wordChat(lexeme, question);

        log.info("[WORD-CHAT] {} ({}) — \"{}\"", strongsId, lexeme.getLemma(), question.strip());
        long t0 = System.currentTimeMillis();
        String answer = router.call(systemPrompt, userPrompt);
        log.info("[WORD-CHAT] {} answered in {}ms ({} chars)",
                 strongsId, System.currentTimeMillis() - t0, answer == null ? 0 : answer.length());

        return Optional.of(answer == null ? "" : answer.trim());
    }
}
```

## 3. Saving Questions to the Vector Store

Spring AI wraps your content into a `Document` object. This object holds the text to be vectorized (the Question) and a map of `metadata` (where you can store the Answer).

```java
import org.springframework.ai.document.Document;
import org.springframework.ai.vectorstore.VectorStore;
import org.springframework.stereotype.Service;
import java.util.Map;

@Service
public class FaqService {

    private final VectorStore vectorStore;

    // Spring automatically injects the PgVectorStore and OpenAI embedding client
    public FaqService(VectorStore vectorStore) {
        this.vectorStore = vectorStore;
    }

    public void saveFaq(String question, String answer) {
        // Create a document containing the question, and attach the answer as metadata
        Document doc = new Document(question, Map.of("answer", answer));
        
        // This single line converts 'question' to a vector and saves it to Postgres!
        vectorStore.add(List.of(doc));
    }
}

```

## 4. Searching by Semantic Meaning

When a user types a question, you use Spring AI’s `SearchRequest`. You can pass a **similarity threshold** (e.g., `0.75`) so it will only return an answer if it's a confident match.

```java
import org.springframework.ai.document.Document;
import org.springframework.ai.vectorstore.SearchRequest;
import org.springframework.ai.vectorstore.VectorStore;
import org.springframework.stereotype.Service;
import java.util.List;

@Service
public class FaqSearchService {

    private final VectorStore vectorStore;

    public FaqSearchService(VectorStore vectorStore) {
        this.vectorStore = vectorStore;
    }

    public String searchAnswer(String userQuery) {
        SearchRequest searchRequest = SearchRequest.query(userQuery)
                .withTopK(1)               // We only want the single best match
                .withSimilarityThreshold(0.75); // Cut off bad results (0.75 = 75% match)

        List<Document> results = vectorStore.similaritySearch(searchRequest);

        if (!results.isEmpty()) {
            Document bestMatch = results.get(0);
            // Retrieve the answer from the metadata map
            return (String) bestMatch.getMetadata().get("answer");
        }

        return "I'm sorry, I couldn't find an answer to that question.";
    }
}

```

Acknowledging those three open items as design-time decisions is smart. They are classic architectural trade-offs when transitioning a vector search system from a basic prototype to production.

Here is a brief analytical overview of each item to guide you when you are ready to implement:

### 1. Threshold Tuning

* **The Reality:** There is no magic number. A `0.75` threshold with an OpenAI embedding model behaves entirely differently than a `0.75` threshold with a Hugging Face model because their dimensional spaces and mathematical bounds differ.
* **The Fix:** Treat the threshold as a configuration property (`@Value("${app.faq.similarity-threshold:0.75}")`) rather than a hardcoded value. This allows you to fine-tune it in production via an environment variable without redeploying code once you analyze user search logs.

### 2. Per-Word vs. Global Search Scope

* **The Reality:** If you have an identifier like `strongsId`, running a completely global search introduces the risk of "semantic drift"—where a question about a completely different concept happens to use similar phrasing and returns a false positive.
* **The Fix:** Spring AI's `SearchRequest` builder supports a `.filterExpression(String)` parameter. When you're ready, you can easily scope the vector search by chaining a metadata filter. This targets only the relevant records, preserving accuracy while saving processing time:
```java
.filterExpression("strongsId == '" + wordId + "'")

```



### 3. Vector-Store Metadata vs. Parallel Relational Table

* **The Reality:** Stuffing everything into the `Document.metadata` map works fine for flat, simple key-value lookups.
